git-cdn cluster …

一个负载均衡把同一个域名上的 HTTP 和 SSH 分发给可扩缩的 git-cdn 实例，每个实例持独立缓存卷、共用同一把烘焙进镜像的 SSH 宿主键。

load balancer ─┬─ HTTP → node ×N（8080，各自缓存卷） （traefik） └─ SSH → node ×N（2222，宿主键烘焙进镜像） origin（演示源站：SSH 密码 + git-shell，HTTP lighttpd + git http-backend）

使用方式

命令里的地址就是你现在访问本页的地址。HTTP 默认代理 github 单站点，路径直通；SSH 走演示源站（密码 demo）——github 的 SSH 只收公钥不收密码。

SSH 端口按 SSH_PORT（默认 2222；标准端口部署时去掉 -p 段）。 客户端信任文件用 examples/cluster/client_known_hosts（gen-keys.sh 生成）。

换个姿势

# 离线上游（网络到不了 github 时） GIT_CDN_NODE_CONFIG=./node.offline.yaml docker compose up -d --wait # 扩到 4 个实例 docker compose --profile metrics up -d --wait --scale node=4 # 客户端无感改写（对已有检出生效） git config --global url."http:///".insteadOf "https://github.com/"
