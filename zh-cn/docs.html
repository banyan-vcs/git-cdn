文档

九份文档，一个仓库

设计记录与代码放在一起——下面每份文档都是主仓库 docs/ 下的一个文件。 英文 README 与中文 README保持同步。

design
设计

架构、鉴权边界、对象存储与补齐、容量与并发、响应交付及其权衡，附代码地图。

config
配置参考

全部配置项及默认值、单/多站点模式、鉴权探测、请求限额、响应 pack 缓存、传输与 TLS、出站代理与私有 CA、客户端凭据绑定。

cache
缓存策略

容量准入、LRU 与租约保护、引用存储与 reftable 迁移、pack 维护、不可达对象保留、响应 pack 缓存，以及 GitHub 不存在仓库的响应处理。

ssh
SSH 密码代理

SSH 前端的配置与运行、首次连接的 host key 自动登记、客户端凭据与认证限速、Git 行为与 Git LFS 透传。

http
HTTP 安全

准入与解析限制、响应暂存与重启恢复、传输配置、多上游凭据绑定。

logging
日志

仓库访问、鉴权探测、对象补齐、响应 pack 与维护的结构化 JSON 事件，各自携带的字段，以及永不记录的内容。

docker
Docker Compose

容器快速启动：HTTP 配置、配置挂载、可选 SSH，以及命名卷的数据管理。

probes
协议实验

设计依据的本地 Git 验证——用 实验脚本可复现，不访问网络、不使用个人凭据。

testing
测试

CI 矩阵、本地正确性套件、可选的真实仓库验证，以及性能测量规则。
