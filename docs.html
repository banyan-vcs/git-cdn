Documentation

Nine documents, one repository

The design record lives with the code — every document below is a file under docs/ in the main repository. The README and its Chinese sibling are kept in parity.

design
Design

Architecture, the authorization boundary, object storage and hydration, capacity and concurrency, response delivery and its tradeoffs, plus a code map.

config
Configuration

Every setting and its default, single- and multi-site modes, authorization probes, request limits, the response pack cache, transport and TLS, outbound proxy and private CA, and client-credential binding.

cache
Cache policy

Size admission, LRU and lease protection, ref storage and reftable migration, pack maintenance, unreachable-object retention, the response pack cache, and GitHub's missing-repository responses.

ssh
SSH password proxy

Configure and run the SSH frontend, automatic first-use host-key enrollment, client credentials and the authentication throttle, Git behavior, and Git LFS passthrough.

http
HTTP security

Admission and parsing limits, response spools and restart recovery, transport configuration, and multi-upstream credential binding.

logging
Logging

The structured JSON events for repository access, authorization probes, hydration, response packs and maintenance, the fields each carries, and what is never logged.

docker
Docker Compose

The container quickstart: HTTP setup, configuration mounts, optional SSH, and state management with named volumes.

probes
Protocol probes

Local Git checks behind the design — reproducible experiments with the probe script, no network, no personal credentials.

testing
Testing

The CI matrix, local correctness suites, optional real-repository validation, and the rules for performance measurement.
